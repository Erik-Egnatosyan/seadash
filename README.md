# SeaDash 0.1: диагностика данных BYD

Приложение для штатной магнитолы BYD (DiLink). Показывает, какие данные машины можно прочитать,
и собирает полный отчёт для разбора. **Только чтение**: в машину ничего не отправляет.

## Как получает данные

1. Подключается к ADB самой магнитолы (`127.0.0.1:5555`).
2. Запускает свой помощник с правами shell.
3. Помощник читает `android.hardware.bydauto` (BYDAutoDeviceManager и устройства BYD).

Без ADB приложение пробует читать напрямую, но на DiLink 5.0 BYD обычно отказывает.

## Установка

1. Магнитола должна быть с включённым ADB или беспроводной отладкой. Если машину русифицировали,
   ADB часто уже включён.
2. Установить APK любым способом:
   - с флешки через файловый менеджер;
   - с компьютера: `adb connect <ip-магнитолы>:5555` и `adb install SeaDash-0.1.apk`.
3. Открыть SeaDash. Если появится «Разрешить отладку по USB?», нажать **«Разрешить»** и отметить **«Всегда»**.
4. В настройках DiLink выключить «Disable background Apps» для SeaDash, если такой пункт есть.

## Что смотреть

- **Плитки**: значение, а под ним сырое число и источник (getter или FID). Серые плитки значат, что данных нет.
- **Строка статуса**: открыт ли порт ADB, работает ли помощник, сколько сигналов с данными.
- **«Полный отчёт»**: собирает все классы BYD, все FID с текущими значениями и версию прошивки.
  Отчёт сохраняется в `Download/SeaDash/`.

## Как передать отчёт

- Подключите магнитолу к точке доступа телефона.
- На телефоне откройте адрес, который показан в приложении (например, `http://192.168.43.12:8080`).
- Там есть список отчётов (кнопка «скачать») и данные в реальном времени.
- Либо скопируйте файл из `Download/SeaDash/` на флешку.

Серийные номера, VIN, IMEI и MAC в отчёте заменены на `<redacted>`.

## Сборка

```
gradlew assembleRelease
```

Готовый файл: `app/build/outputs/apk/release/app-release.apk`. Нужны JDK 17 и Android SDK 35.
